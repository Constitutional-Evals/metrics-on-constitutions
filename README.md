# Metrics on Constitutions

Research projects studying distances and similarity structures between AI constitutions.

- **[Granite anchor behavioral TVD](behavioral-tvd-granite-anchor/README.md):** a self-contained research snapshot measuring conditional binary-action total-variation distances for 24 Constitutional-Evals anchors. The official completed prefix covers 220 scenarios; a separate complete-case supplement covers 239. Data collection is paused, and Batch 12 remains incomplete.

Each subproject retains its own package configuration, documentation, provenance, and reproduction instructions. Start commands from the directory specified by that subproject.

Future reviewed updates follow the [publication and synchronization workflow](PUBLISHING.md).
